# 🌙 Eid News Network — Android wrapper

Capacitor wrapper that packages the [eid](https://github.com/abourdim/eid) web app as an installable **Android APK**.

> عيد · Eid News Network

A single-page Eid Mubarak greeting card styled as a live TV news broadcast — Islamic calligraphy meets hacker drama. Hijri date, Eid countdown, scrolling ticker, terminal sequence, share button. Personalize with `?to=Name`.

## Quick start

```bash
./manage.sh    # auto-detects your OS, then opens the menu
```

Build, test on emulator, and prepare a Play Store release from a single guided menu. See [WORKSHOP.html](WORKSHOP.html) for the full step-by-step guide.

## Download the latest APK

[📦 v1.0-debug release](https://github.com/abourdim/eid-android/releases/latest) · [![QR](releases/download-qr.svg)](https://github.com/abourdim/eid-android/releases/latest)

Scan the QR with an Android phone, or `adb install -r eid-v1.0-debug.apk`.

## Capabilities required at runtime

- Standard WebView (no special hardware)
